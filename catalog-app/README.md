# Fictional campus supplier portal

Read-only local product, purchasing policy, and meal-plan fixture. Nine products span potatoes, rice, and carrots. All commercial, preparation, cooked-yield, dietary, and delivery facts are synthetic. Service date is persisted on initialization; reset creates a new fixture date.

The portal accepts GET/HEAD only. Application-owned tools assess products and record approved orders through the private store; browsing cannot submit a purchase. This package is installed into the presenter container independently of the agent application.
